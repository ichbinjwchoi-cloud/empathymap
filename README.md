# 공감지도 만들기 (중2 도덕 수업용)

조별로 실시간 접속해서 공감지도(Think & Feel · Hear · Say & Do · Pain · Gain)를 함께 만드는 웹앱입니다.
GitHub + Render 무료 플랜 + 구글 시트(Apps Script, 무료)로 운영합니다. 결제 정보나 Google Cloud Console은 필요 없어요.

## 주요 기능

**학생 (갤럭시탭에 맞춤)**
- 이름 · 반(1~8반) · 조를 골라 입장
- 📌 오늘의 미션: "모든 칸에 포스트잇 붙이기"와 "한 사람당 2장 이상 쓰기"를 화면 위에 보여 주고, 다 하면 ✓ 표시
- 비어 있는 칸은 점선으로 표시되고 "눌러서 첫 포스트잇 붙이기" 안내가 나옴
- 포스트잇 쓰기: Enter는 줄바꿈, 다 쓰면 **[붙이기] 버튼**을 눌러야 붙음
- 포스트잇을 누르면: 내 것은 고치기·색 바꾸기·칸 옮기기·지우기, 친구 것은 칸 옮기기
- 가운데 원에 선생님이 올린 주제 사진이 보이고, 누르면 크게 볼 수 있음
- 인터넷이 잠깐 끊겨도 쓴 내용은 연결되면 저장되고, 두 번 붙지 않음

**교사 (입장 화면 아래 `교사 모드` → 코드 9812, 노트북·TV에 맞춤)**
- 1~8반 탭, 모든 조 진행 상황(칸별 장수, 채운 칸, 학생별 장수 — 2장 미만은 주황색, 접속 중이면 초록 점)
- 📷 주제 사진 올리기 / 바꾸기 / 빼기 ("1~8반 모두에 적용"을 체크하면 모든 반에 한 번에)
- 주제 바꾸기, 조 수, 🔒 편집 잠그기, CSV 내려받기, 조별 / 반 전체 지우기
- 조 카드를 누르면 그 조 공감지도를 크게 보기 — 키보드 ← → 로 다른 조, Esc로 돌아가기
- 오른쪽 위 **가− / 가+** 로 글자 크기 조절(TV는 가+ 두세 번), **⛶** 로 전체 화면
- 오른쪽 위 저장 표시: ☁️ 자동 저장됨 / ⚠️ 저장 오류 / ⚠️ 구글 시트 저장 꺼짐

## 구글 시트 자동 저장 (꼭 설정해 주세요)

Render 무료 서버는 잠들거나 다시 시작될 때 서버 안의 파일이 지워져요.
그래서 포스트잇과 사진을 **선생님의 구글 시트에 자동으로 저장**하고, 서버가 켜질 때 다시 불러와요.

1. 구글 드라이브에서 **새 구글 시트**를 만들어요. (이름 예: 공감지도 저장)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 눌러요.
3. 원래 있던 코드를 모두 지우고, 이 저장소의 `google-apps-script.gs` 내용을 붙여 넣어요.
4. 맨 위 `const SECRET = '여기에-비밀번호를-적어-주세요';` 의 따옴표 안을 아무도 모르는 영어+숫자로 바꿔요. (예시를 그대로 쓰지 말고 직접 지어 주세요)
5. 💾 저장 → 위쪽 함수 목록에서 `setup` 고르고 **실행** → 권한 승인 창이 뜨면 내 계정으로 **허용**
   ("Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**. 내가 만든 스크립트라 괜찮아요.)
6. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** 누르고, 나온 **웹 앱 URL**(…/exec 로 끝남)을 복사
7. Render → empathymap 서비스 → **Environment** → 두 개 추가 후 저장
   - `SHEET_URL` = 복사한 웹 앱 URL
   - `SHEET_SECRET` = 4번에 쓴 비밀번호
8. Render가 다시 배포되면 교사 화면 오른쪽 위에 **☁️ 자동 저장됨**이 보이면 끝!

시트에 생기는 탭
- **포스트잇(현재)**: 지금 붙어 있는 포스트잇 (계속 자동으로 바뀜)
- **기록(모든 활동)**: 붙이기·고치기·지우기가 시간 순서로 쌓임 — 반을 지워도 여기에는 남아요
- `_data`, `_img`(숨김): 앱이 쓰는 저장 공간이라 고치거나 지우지 마세요

> Apps Script 코드를 나중에 고치면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영돼요. (URL은 그대로)

## Render 배포

1. Render 대시보드 → **New → Web Service** → 이 저장소 선택
2. Runtime: **Node** · Build Command: `npm install` · Start Command: `npm start` · Instance Type: **Free**
3. (선택) Environment에 `TEACHER_CODE`를 추가하면 교사 코드를 9812가 아닌 번호로 바꿀 수 있어요.
4. GitHub에 파일이 바뀌면 Render가 자동으로 다시 배포해요.

## 수업 팁

- 무료 서버는 15분 동안 아무도 안 쓰면 잠들어요. **수업 1~2분 전에 교사 화면을 먼저 열어 두세요.** (수업 중에는 화면이 열려 있으면 잠들지 않아요)
- 수업 중에 새 버전을 배포하면 몇십 초 동안 연결이 끊겼다 다시 붙어요. 큰 수정은 수업이 없을 때 해 주세요.

## 파일 구성

```
server.js              실시간 서버 (Express + Socket.io) + 구글 시트 자동 저장
google-apps-script.gs  구글 시트에 붙여 넣는 저장용 코드
public/index.html      화면 구조
public/app.js          학생 · 교사 화면 동작
public/style.css       디자인 (갤럭시탭 · 노트북 · TV 맞춤)
```
