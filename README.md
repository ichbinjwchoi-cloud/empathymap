# 공감지도 만들기 (중2 도덕 수업용)

조별로 실시간 접속해서 공감지도(Think & Feel · Hear · Say & Do · Pain · Gain)를 함께 만드는 웹앱입니다.
유료 API나 구글 클라우드 설정 없이 GitHub + Render 무료 플랜으로 운영할 수 있습니다.

## 주요 기능

**학생**
- 이름 · 반(1~8반) · 조를 골라 입장
- 각 칸의 `+ 붙이기`로 포스트잇 작성 (색 6가지, 200자까지, Enter로 붙이기 / Shift+Enter 줄바꿈)
- 포스트잇에 작성자 이름 표시, 내 포스트잇에는 "(나)" 표시
- 내가 쓴 포스트잇만 고치기 · 지우기 가능
- 포스트잇을 끌어서 다른 칸으로 옮기기 (태블릿은 ⇄ 버튼으로 옮기기)
- 같은 조 접속자 이름이 위쪽에 표시, 조원이 붙인 포스트잇이 바로 나타남
- 새로고침해도 자동으로 다시 입장

**교사 (입장 화면 아래 `교사 모드` → 코드 9812)**
- 1~8반 탭을 눌러 반 바꾸기
- 모든 조의 진행 상황을 한 화면에: 접속자, 칸별 포스트잇 수, 채운 칸(○/5), 최근 포스트잇, 최근 활동 시각
- 조 카드를 누르면 그 조의 공감지도를 크게 보기 (‹ › 로 다른 조로 넘기기) — 수업 중 화면에 띄워 발표용으로 쓰기 좋아요
- 주제 바꾸기 (기본: 난민 → 질문 문구가 "노인들이 느끼는 감정은…"처럼 자동으로 바뀜)
- 조 수 바꾸기 (1~10개)
- 🔒 편집 잠그기: 학생들이 쓰기·고치기를 못 하게 멈춤 (발표 · 정리 시간용)
- 어떤 포스트잇이든 고치기 · 지우기, "선생님" 이름으로 포스트잇 붙이기
- CSV 내려받기 (엑셀에서 바로 열림), 조별 / 반 전체 지우기

## 내 컴퓨터에서 실행해 보기

```bash
npm install
npm start
```
브라우저에서 http://localhost:3000 을 엽니다. 창을 여러 개 열어 다른 이름으로 들어가 보면 실시간으로 함께 붙는 것을 볼 수 있어요.

## Render에 배포하기 (디베이트온과 같은 방법)

1. GitHub에서 새 저장소(예: `empathy-map`)를 만들고 이 폴더의 파일을 모두 올립니다.
2. Render 대시보드 → **New → Web Service** → 방금 만든 저장소 선택
3. 설정
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
4. (선택) Environment에 `TEACHER_CODE` 를 추가하면 교사 코드를 9812가 아닌 다른 번호로 바꿀 수 있어요.
5. 배포가 끝나면 나오는 주소(`https://…onrender.com`)를 학생들에게 알려 주면 됩니다.

## 꼭 알아 둘 점 (Render 무료 플랜)

- **15분 동안 아무도 접속하지 않으면 서버가 잠듭니다.** 수업 시작 1~2분 전에 교사가 먼저 주소를 열어 깨워 두세요.
- 포스트잇은 서버의 `data.json` 파일에 저장됩니다. 무료 플랜은 **서버가 다시 시작되거나 새로 배포되면 이 파일이 지워질 수 있어요.**
  수업이 끝나면 교사 화면에서 **CSV 내려받기**로 결과를 꼭 보관해 두세요.
- 한 반(30명 안팎)이 동시에 쓰는 정도는 무료 플랜으로 충분합니다.
